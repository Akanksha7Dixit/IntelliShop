# 🤖 AI Recommendation System

An AI-based recommendation system that suggests similar products using embeddings instead of keyword matching.

---

## 📌 Status

🚧 Still in development, improvements are ongoing.

---

## 🚀 Features

- Semantic search using AI
- Smart recommendations
- Fast similarity matching
- MERN stack (React, Node.js, MongoDB)

---

## 🛠️ Tech Stack

- Frontend: React, Tailwind CSS  
- Backend: Node.js, Express  
- Database: MongoDB  
- AI: OpenAI Embeddings  

---

## ⚙️ Setup

```bash
git clone https://github.com/your-username/ai-recommendation-system.git
cd ai-recommendation-system

cd backend
npm install

cd ../frontend
npm install
```

Create `.env` in backend:

```env
OPENAI_API_KEY=your_api_key
MONGO_URI=your_mongodb_uri
PORT=5000
```

Run project:

```bash
# backend
npm run dev

# frontend
npm start
```
